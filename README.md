# Omar

Eight websites built with AI in my free time. Every one opens the real, running site.

**Live:** https://omarjnbz.vercel.app/

## What's on the page

- The headline arrives word by word, then the first site rises under it
- Every project is a silent loop of the real site in a black frame, passing through the middle of the screen one after another; click one for its details
- Arminak Caravan opens into the whole system behind it: logo, two openings, the catalogue she runs, brand book and handover

## Built with

Plain HTML, CSS and JavaScript with no build step. Animation by GSAP and ScrollTrigger. Archivo and Martian Mono.
Fonts and scripts are served from this repository, and the page sets no cookies. Visits are counted with Vercel Web Analytics,
which is cookieless and served from this same domain; there are no third-party trackers.
